# Asadbek Istamov — Personal Portfolio

Creative, responsive personal portfolio website built with HTML, CSS and vanilla JavaScript.

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Open the repository Settings.
2. Go to Pages.
3. Under Build and deployment, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then Save.
5. GitHub will publish the site at `https://asadbekistamov99-hash.github.io/me/` after deployment completes.

The site includes dark/light themes, responsive navigation, project cards, skills, interests and contact links.
